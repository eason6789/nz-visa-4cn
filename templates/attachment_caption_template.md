# 附件说明文字模板 / Attachment Caption Template

## 格式说明
用于无法归类的材料，生成简洁的英文说明页，附在材料首页之前或整个PDF之前

## 标准附件说明页格式

```
ATTACHMENT [N]
[材料中文名称]

Description:
[Brief description of what this document is and why it is included]

Key Information Extracted:
- [Key field 1]: [Value]
- [Key field 2]: [Value]
- [Key field 3]: [Value]

Note:
[Any relevant notes for the visa officer]

Translated by: [TRANSLATOR_NAME]
[TRANSLATOR_CERTIFICATION]
```

## 示例：旅行历史截图附件

```
ATTACHMENT 1
Travel History — Social Media Evidence

Description:
This attachment contains screenshots of social media posts documenting the applicant's
previous international travels, serving as supplementary evidence of travel history.

Countries Visited:
- Japan (March 2026)
- Switzerland (September 2025)
- Italy (October 2025)
- South Korea (May 2025)
- Thailand (October 2023)
- Egypt (April 2024)
- Singapore (October 2024)

Note:
Screenshots are provided in chronological order from oldest to most recent.
All posts were originally published on WeChat Moments (a Chinese social media platform).

Translated by: [TRANSLATOR_NAME]
[TRANSLATOR_CERTIFICATION]
```

## 示例：其他资产证明附件

```
ATTACHMENT 2
Proof of Assets — Vehicle Registration Certificate

Description:
This attachment contains the vehicle registration certificate (机动车登记证书) for the
applicant's personal automobile, serving as additional evidence of assets and strong
ties to China.

Key Information:
- Owner: [APPLICANT_NAME]
- Vehicle Type: Sedan
- License Plate: 京A-12345
- Issue Date: [DATE]

Translated by: [TRANSLATOR_NAME]
[TRANSLATOR_CERTIFICATION]
```

```

Description:

Key Information:

[TRANSLATOR_CERTIFICATION]
```
